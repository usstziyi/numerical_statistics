这两个问题问得非常好，正好是 t 检验里最核心的两个“为什么”。我分别详细解释。

---

# 问题一：为什么 t-stat 要去查 t 分布曲线（df=4）？

## 1. 核心原因：t-stat 本身是一个随机变量

你算出来的 t = 1.43，看起来是一个固定的数。但你要意识到：

> **如果重新抽 5 个学生，你会得到另一个样本均值、另一个样本标准差，从而算出另一个 t 值。**

也就是说，t-stat 不是一个固定的常数，而是一个**随机变量**——它随着抽样不同而不同。

既然它是随机变量，它就有自己的**概率分布**。问题就变成：

> 在零假设 \(H_0\) 成立时，t-stat 服从什么分布？

答案是：**t 分布**，自由度为 \(df = n - 1 = 4\)。

---

## 2. 为什么是 t 分布，而不是正态分布？

这是关键。

### 如果总体标准差 \(\sigma\) 已知

那么：

\[
z = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}
\]

这个 \(z\) 服从**标准正态分布** \(N(0,1)\)。

### 但现实中 \(\sigma\) 通常未知

我们只能用样本标准差 \(s\) 来代替 \(\sigma\)：

\[
t = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}
\]

问题来了：\(s\) 本身也是从样本算出来的，它也有随机波动。

- 有时候 \(s\) 偏小 → t 偏大
- 有时候 \(s\) 偏大 → t 偏小

这种“额外的随机性”让 t 的分布比正态分布**尾部更厚**。

这就是 **t 分布**。

---

## 3. 为什么自由度是 df = n − 1 = 4？

因为计算样本标准差 \(s\) 时，你用了样本均值 \(\bar{x}\) 作为中间步骤。

- 样本均值消耗了 1 个自由度。
- 剩下 \(n - 1\) 个自由度用来估计方差。

所以：

\[
df = n - 1 = 5 - 1 = 4
\]

自由度决定了 t 分布的“厚尾程度”：

- df 越小 → 尾部越厚 → 同样的 t 值，p-value 越大。
- df 越大 → 越接近正态分布。

---

## 4. 为什么要查这条曲线？——为了得到 p-value

p-value 的定义是：

> 在 \(H_0\) 成立的前提下，得到当前 t 值或更极端 t 值的概率。

这个“概率”就是**曲线下的面积**。

所以你必须知道：

1. t 在 \(H_0\) 下服从什么分布 → t 分布（df=4）
2. 你的 t 值落在这条曲线的哪个位置 → t = 1.43
3. 从 t = 1.43 往极端方向数面积 → p-value

没有这条曲线，你就不知道“t = 1.43 算大还是算小”。

---

## 5. 一句话总结

> **t-stat 是随机变量，在 \(H_0\) 下服从自由度为 \(n-1\) 的 t 分布。查这条曲线，就是为了知道“在 \(H_0\) 下，出现像 1.43 这么极端的 t 值的概率有多大”，这个概率就是 p-value。**

---

# 问题二：为什么 μ > 70 往右看，μ < 70 往左看？

## 1. 先看 t-stat 的符号代表什么

\[
t = \frac{\bar{x} - \mu_0}{SE}
\]

分母 \(SE\) 永远是正的，所以 t 的符号完全由分子决定：

- \(\bar{x} > \mu_0\) → 分子为正 → **t > 0**（样本均值高于零假设值）
- \(\bar{x} < \mu_0\) → 分子为负 → **t < 0**（样本均值低于零假设值）

所以：

> **t 的正负，代表样本均值偏离零假设的方向。**

- t > 0：数据往“大”的方向偏
- t < 0：数据往“小”的方向偏

---

## 2. 备择假设的方向决定“极端”是哪一侧

p-value 的定义是：

> 在 \(H_0\) 下，得到当前结果**或更极端**结果的概率。

关键在“更极端”这三个字——**极端的方向由备择假设决定**。

### 情况 A：\(H_1: \mu > 70\)

备择假设说：总体均值**大于** 70。

那么“支持 \(H_1\) 的证据”就是：

> 样本均值**越大越好**，t 值**越大越好**。

所以“更极端”= t 值**更大**= 往**右**看。

p-value = 曲线下 \(t \geq 1.43\) 的面积（右尾）。

```
                     p-value
                       ↓
                 ┌─────┐
        ┌────────┤     ├────────┐
        │        │     │        │
────────┴────────┴─────┴────────┴────→ t
       -4      -2  0  1.43   4
                       ↑
                   你的 t-stat
```

---

### 情况 B：\(H_1: \mu < 70\)

备择假设说：总体均值**小于** 70。

那么“支持 \(H_1\) 的证据”就是：

> 样本均值**越小越好**，t 值**越小越好**（越负越好）。

所以“更极端”= t 值**更小**= 往**左**看。

p-value = 曲线下 \(t \leq 1.43\) 的面积。

因为 1.43 在中心右侧，往左看几乎覆盖整个曲线：

```
        p-value（几乎整个曲线）
   ←──────────────────────────
                 ┌────────────┐
        ┌────────┤            ├────────┐
        │        │            │        │
────────┴────────┴────────────┴────────┴────→ t
       -4      -2  0        1.43      4
                              ↑
                          你的 t-stat
```

---

## 3. 一个直观类比

想象你在测体温，正常体温 \(\mu_0 = 37°C\)。

- 如果你怀疑“发烧”（\(\mu > 37\)），那么**体温越高越支持你的怀疑** → 往右看。
- 如果你怀疑“体温过低”（\(\mu < 37\)），那么**体温越低越支持你的怀疑** → 往左看。

t 分布曲线上的“极端方向”，永远和备择假设的方向一致。

---

## 4. 双尾检验怎么办？

如果 \(H_1: \mu \neq 70\)，那么两个方向都算极端：

\[
p = P(t \geq |1.43|) + P(t \leq -|1.43|)
\]

也就是左右两尾面积之和。

---

## 5. 一句话总结

> **t 的符号告诉你数据偏向哪边；备择假设告诉你“哪边才算支持我”。两者方向一致时，p-value 才可能小；方向相反时，p-value 会很大。**

- \(\mu > 70\) → 支持 H₁ 的证据在右边 → 往右看
- \(\mu < 70\) → 支持 H₁ 的证据在左边 → 往左看
- \(\mu \neq 70\) → 两边都算 → 双尾

你这句话其实已经抓住了双尾检验的直觉，但有一个**关键的概念混淆**需要澄清：

> **“往 70 的左右两边看” 和 “往 t 分布曲线的左右两边看” 不是同一件事，但它们是对应的。**

我帮你把这两层意思捋清楚。

---

## 1. 你说的“往 70 的左右两边看”是什么意思？

你的直觉是：

- \(H_1: \mu \neq 70\) 意味着：
  - 总体均值**大于 70** 算极端；
  - 总体均值**小于 70** 也算极端。
- 所以“偏离 70 越远越好”，两个方向都算。

这个直觉**完全正确**。

问题在于：**t 分布曲线的横轴不是 \(\mu\)，而是 t 值。**

---

## 2. t 分布曲线的横轴是什么？

t 分布曲线的横轴是：

\[
t = \frac{\bar{x} - \mu_0}{SE}
\]

它衡量的是：

> **样本均值 \(\bar{x}\) 偏离零假设值 \(\mu_0 = 70\) 了多少个标准误。**

所以横轴上的 t 值和 \(\mu\) 的偏离方向是一一对应的：

| 样本均值 \(\bar{x}\) | t 值 | 含义 |
|---|---|---|
| \(\bar{x} > 70\) | t > 0 | 数据偏向“大于 70” |
| \(\bar{x} = 70\) | t = 0 | 数据正好等于 70 |
| \(\bar{x} < 70\) | t < 0 | 数据偏向“小于 70” |

所以：

> **“往 70 的左右两边看” 等价于 “往 t 分布曲线的左右两边看”。**

- \(\mu > 70\) 的方向 → t > 0 → 曲线**右尾**
- \(\mu < 70\) 的方向 → t < 0 → 曲线**左尾**

---

## 3. 双尾 p-value 的公式在说什么？

\[
p = P(t \geq |1.43|) + P(t \leq -|1.43|)
\]

这里的 \(|1.43| = 1.43\)，所以：

\[
p = P(t \geq 1.43) + P(t \leq -1.43)
\]

翻译成人话：

- 第一项 \(P(t \geq 1.43)\)：**右尾**面积，对应“样本均值远大于 70”的极端情况。
- 第二项 \(P(t \leq -1.43)\)：**左尾**面积，对应“样本均值远小于 70”的极端情况。

这两个尾部合起来，就是：

> **在 \(H_0\) 下，样本均值偏离 70 的程度（无论哪个方向）达到或超过当前观测值的概率。**

---

## 4. 为什么用 \(|1.43|\) 和 \(-|1.43|\)？

因为双尾检验关心的是**偏离的绝对大小**，不关心方向。

- 你的 t = +1.43，偏离中心 1.43 个单位。
- 对称地，-1.43 也偏离中心 1.43 个单位。
- 这两个点一样“极端”。

所以双尾 p-value 就是：

> **t 的绝对值 ≥ 1.43 的概率。**

\[
p = P(|t| \geq 1.43)
\]

画出来就是左右两尾面积之和。

---

## 5. 用图直观理解

```
        双尾 p-value = 左尾 + 右尾
        ↓                        ↓
   ┌────┐                    ┌────┐
   │    │                    │    │
───┴────┴────────────────────┴────┴───→ t
  -1.43   0                1.43
    ↑                        ↑
  左尾                     右尾
（对应 μ<70）            （对应 μ>70）
```

- 左尾：对应“样本均值远小于 70”
- 右尾：对应“样本均值远大于 70”
- 中间那块大的面积：对应“样本均值接近 70”，不算极端

---

## 6. 回到你的疑问

你说：

> “μ ≠ 70 不是应该往 70 的左右两边看吗？”

对，但要注意：

- **往 70 的左右两边看** = 在 \(\mu\) 的尺度上，两边都算极端。
- **在 t 分布曲线上**，这个“两边”就变成了：
  - 右边（t > 0）对应 \(\mu > 70\)
  - 左边（t < 0）对应 \(\mu < 70\)

所以公式里的 \(P(t \geq 1.43) + P(t \leq -1.43)\)，正是：

> **把 \(\mu\) 偏离 70 的两个方向，分别映射到 t 分布曲线的右尾和左尾，然后把两块面积加起来。**

---

## 7. 一句话总结

> **双尾检验确实是“往 70 的左右两边看”，但在 t 分布曲线上，这两边就表现为左尾和右尾。公式里的两项，正是把这两个方向的极端概率分别算出来再相加。**

所以你的直觉没错，只是要记住：

> **t 分布曲线的横轴是“偏离 70 的标准误倍数”，不是 \(\mu\) 本身。**
