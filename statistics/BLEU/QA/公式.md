一样，**这两个公式完全等价**。

第一个是：

\[
BLEU = BP\,(p_1p_2p_3p_4)^{1/4}
\]

第二个是：

\[
BLEU
=
BP\cdot
\exp\left(
\frac14\sum_{n=1}^{4}\ln p_n
\right)
\]

从第二个公式展开：

\[
\sum_{n=1}^{4}\ln p_n
=
\ln p_1+\ln p_2+\ln p_3+\ln p_4
\]

所以：

\[
BLEU
=
BP\cdot
\exp\left[
\frac14
(\ln p_1+\ln p_2+\ln p_3+\ln p_4)
\right]
\]

利用对数性质：

\[
\ln p_1+\ln p_2+\ln p_3+\ln p_4
=
\ln(p_1p_2p_3p_4)
\]

得到：

\[
BLEU
=
BP\cdot
\exp\left[
\frac14\ln(p_1p_2p_3p_4)
\right]
\]

又因为：

\[
e^{a\ln x}=x^a
\]

所以：

\[
\boxed{
BLEU
=
BP\,(p_1p_2p_3p_4)^{1/4}
}
\]

因此两种写法只是形式不同：

\[
\boxed{
(p_1p_2p_3p_4)^{1/4}
=
\exp\left(
\frac14\sum_{n=1}^{4}\ln p_n
\right)
}
\]

本质上都是在计算 \(p_1,p_2,p_3,p_4\) 的**几何平均数**。

更一般地，如果 BLEU 使用 \(N\)-gram：

\[
\boxed{
BLEU
=
BP\cdot
\exp\left(
\sum_{n=1}^{N}w_n\ln p_n
\right)
}
\]

标准 BLEU-4 中：

\[
w_1=w_2=w_3=w_4=\frac14
\]

所以就变成：

\[
BLEU
=
BP\cdot(p_1p_2p_3p_4)^{1/4}
\]

你前面那个 SacreBLEU 例子，用的就是这两个完全等价的公式。
