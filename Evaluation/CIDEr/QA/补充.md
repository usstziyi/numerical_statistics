支持通过 `evaluate.load()` 使用 **社区实现的 CIDEr**，但目前它不是 Hugging Face Evaluate 官方 `evaluate-metric` 集合里的内置指标。Evaluate 官方文档明确支持通过 Hub 的仓库 ID 加载社区 metric。:chatgpt-content-reference{index="0"}

例如目前可以这样：

```python
import evaluate

cider = evaluate.load("sunhill/cider")

predictions = [
    "a cat is sitting on the mat"
]

references = [
    [
        "a cat sits on the mat",
        "a cat is sitting on a mat",
        "there is a cat on the mat"
    ]
]

results = cider.compute(
    predictions=predictions,
    references=references
)

print(results)
```

这个社区实现的源码中确实使用：

```python
CiderScorer(n=4, sigma=6.0)
```

并返回：

```python
{
    "cider_score": ...
}
```

也就是说它计算到 **1～4 gram**，并且 `sigma=6.0`；源码显示这是带长度 Gaussian penalty 等机制的 CIDEr scorer 实现。:chatgpt-content-reference{index="1"}

### 和你前面学的指标有一点区别

你之前可以直接写：

```python
evaluate.load("bleu")
evaluate.load("rouge")
evaluate.load("bertscore")
```

而 CIDEr 更适合写成：

```python
evaluate.load("sunhill/cider")
```

因为这是指定 **Hugging Face Hub 上的社区 metric 仓库**，而不是 Evaluate 官方内置的 `cider`。Evaluate 官方也说明社区模块可以通过完整 repository ID 加载。:chatgpt-content-reference{index="2"}

不过，如果你是准备在 **EEG2Text 论文实验**里正式计算 CIDEr，我更建议我们接下来看看 **`pycocoevalcap` 的 CIDEr 实现**。图像描述领域很多论文/benchmark 使用 COCO caption evaluation 那套实现，论文复现实验时“用哪个 CIDEr 实现”比单纯能不能 `evaluate.load()` 更重要。
