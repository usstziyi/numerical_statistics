ROUGE 是一整类文本生成评价指标的总称，ROUGE-L 是其中的一种。

可以把关系理解成：

\[
\boxed{\text{ROUGE} \supset \text{ROUGE-L}}
\]

ROUGE 全称是 **Recall-Oriented Understudy for Gisting Evaluation**，最初主要用于自动摘要评价。它并不是单独一个公式，而是一个指标家族，例如：

- **ROUGE-1**：比较 unigram，也就是单词/字的重叠
- **ROUGE-2**：比较 bigram 重叠
- **ROUGE-N**：一般化到 n-gram 重叠
- **ROUGE-L**：基于 **Longest Common Subsequence，最长公共子序列**
- 还有 ROUGE-S、ROUGE-W 等变体

其中 ROUGE-L 的 `L` 就代表：

\[
\boxed{L=\text{Longest Common Subsequence}}
\]

比如参考文本：

```text
the cat is on the mat
```

生成文本：

```text
the cat was on mat
```

两者的最长公共子序列可以是：

```text
the cat on mat
```

长度为 4。

注意这里是**子序列**，不是“连续子串”，因此中间允许跳过词，但顺序不能改变。

ROUGE-L 通常基于这个最长公共子序列计算 Precision 和 Recall：

\[
P_{LCS}
=
\frac{LCS(X,Y)}{|X|}
\]

\[
R_{LCS}
=
\frac{LCS(X,Y)}{|Y|}
\]

其中一般可以把 \(X\) 看作模型生成文本，\(Y\) 看作参考文本。

然后再组合成类似 F1 的分数：

\[
F_{LCS}
=
\frac{(1+\beta^2)P_{LCS}R_{LCS}}
{R_{LCS}+\beta^2P_{LCS}}
\]

如果简单取 \(\beta=1\)，就是普通的 F1：

\[
F_1
=
\frac{2PR}{P+R}
\]

所以最重要的区别可以记成：

| 指标 | 比较什么 |
|---|---|
| ROUGE-1 | 单个词/字是否重叠 |
| ROUGE-2 | 连续两个词/字是否重叠 |
| ROUGE-N | n-gram 重叠 |
| **ROUGE-L** | **最长公共子序列 LCS** |

一个很重要的区别是：**ROUGE-N 更看重局部连续匹配，而 ROUGE-L 能一定程度考虑整个句子的顺序结构。**

例如：

```text
参考：A B C D E
预测：A B X C D
```

ROUGE-2 会检查：

```text
AB
BC
CD
DE
```

和

```text
AB
BX
XC
CD
```

所以只能匹配部分 bigram。

但 ROUGE-L 可以找到：

```text
A B C D
```

虽然 `B` 和 `C` 在预测中间隔了一个 `X`，仍然属于公共子序列。

因此一句话总结：

\[
\boxed{
\text{ROUGE 是指标家族，ROUGE-L 是基于最长公共子序列的 ROUGE 变体}
}
\]

如果你现在是在系统学习 NLP 评价指标，可以进一步把它们分成：**BLEU/chrF/ROUGE 属于表面重叠型指标，而 BERTScore/COMET 更偏语义型指标。**
