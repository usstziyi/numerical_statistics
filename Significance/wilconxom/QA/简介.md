可以。你可以把 **Wilcoxon** 和 **Mann–Whitney U** 理解成 t 检验对应的两类经典**非参数检验**：

| 场景 | 参数检验 | 非参数检验 |
|---|---|---|
| 单样本 / 配对样本 | one-sample t-test / paired t-test | **Wilcoxon signed-rank test** |
| 两个独立样本 | independent t-test | **Mann–Whitney U test** |

最重要的一句话是：

> **Wilcoxon 处理“成对/单样本差值”，Mann–Whitney U 处理“两个独立组”。**

---

## 1. 为什么需要非参数检验？

比如你做 EEG2Text，有两个模型：

```text
Model A BLEU:
[0.31, 0.35, 0.28, 0.40, 0.33]

Model B BLEU:
[0.36, 0.38, 0.30, 0.44, 0.37]
```

如果这两个数组分别对应**同样的 5 个被试**，你真正关心的是：

\[
d_i = B_i-A_i
\]

例如：

\[
[0.05,0.03,0.02,0.04,0.04]
\]

配对 t 检验主要研究：

\[
H_0:\mu_d=0
\]

但它对**差值的正态性**有一定假设。

如果样本很小、数据明显偏态、有异常值，或者你不希望依赖正态分布假设，可以使用：

\[
\boxed{\text{Wilcoxon signed-rank test}}
\]

它不直接研究均值，而主要基于数据的**排序 rank**。

---

# 2. Wilcoxon signed-rank test

中文一般叫：

> **Wilcoxon 符号秩检验**

完整名称：

> Wilcoxon signed-rank test

它适合：

- 一个样本和某个基准比较
- 同一批对象前后比较
- 同一批被试上两个模型比较

也就是**配对数据**。

---

## 3. Wilcoxon 的核心思想

假设：

```text
A = [71, 74, 69, 76, 72]
B = [75, 76, 68, 80, 75]
```

首先计算差值：

\[
d_i=B_i-A_i
\]

得到：

```text
4, 2, -1, 4, 3
```

Wilcoxon 不直接拿这些差值计算均值。

它先看绝对值：

```text
|d| = 4, 2, 1, 4, 3
```

然后排序。

大致为：

```text
绝对差    rank
1          1
2          2
3          3
4          4.5
4          4.5
```

再把原来的正负号放回来：

```text
差值      rank
+4        +4.5
+2        +2
-1        -1
+4        +4.5
+3        +3
```

正秩和：

\[
W_+=4.5+2+4.5+3=14
\]

负秩和：

\[
W_-=1
\]

如果两个方法实际上没有系统差异，那么正差、负差应该比较平衡：

\[
W_+\approx W_-
\]

但这里：

\[
14 \gg 1
\]

就说明 B 很可能整体高于 A。

所以 Wilcoxon 的基本思想就是：

> 不仅看“谁大谁小”，还看**差异大小的排名**。

这也是它比单纯的 sign test 信息利用得更多的地方。

---

# 4. Wilcoxon 检验的假设

常见双侧检验：

\[
H_0:
\text{差值分布关于 0 对称}
\]

通常可以直观理解为：

> 两组配对数据不存在系统性的中心位置差异。

备择假设：

\[
H_1:
\text{存在系统差异}
\]

Python：

```python
from scipy.stats import wilcoxon

A = [71, 74, 69, 76, 72]
B = [75, 76, 68, 80, 75]

result = wilcoxon(
    A,
    B,
    alternative="two-sided"
)

print("W statistic:", result.statistic)
print("p-value:", result.pvalue)
```

如果：

```text
p < 0.05
```

一般写成：

> The difference was statistically significant according to the Wilcoxon signed-rank test.

这里的 p-value 仍然叫：

> **p-value / 显著性检验的 p 值**

并不是 Wilcoxon 有一种特殊名字的 p 值。

---

# 5. Wilcoxon 和 paired t-test 对应

关系非常重要：

```text
paired t-test
      ↓
要求差值近似正态
      ↓
如果不满足
      ↓
Wilcoxon signed-rank test
```

例如：

```python
from scipy.stats import ttest_rel, wilcoxon

A = [71, 74, 69, 76, 72]
B = [75, 76, 68, 80, 75]

print(ttest_rel(A, B))
print(wilcoxon(A, B))
```

两者研究的问题相似，但数学机制不一样。

### paired t-test

主要利用：

\[
\text{差值的均值}
\]

### Wilcoxon

主要利用：

\[
\text{差值的符号 + 排名}
\]

---

# 6. Mann–Whitney U test

再看另一种情况。

假设你有：

```text
模型 A：5 个被试
模型 B：另外 5 个被试
```

例如：

```python
A = [71, 74, 69, 76, 72]
B = [80, 79, 83, 75, 81]
```

这里：

```text
A[0]
```

和：

```text
B[0]
```

没有配对关系。

所以不能使用 Wilcoxon signed-rank。

这时可以使用：

\[
\boxed{\text{Mann–Whitney U test}}
\]

也叫：

> Mann–Whitney–Wilcoxon test

或者：

> Wilcoxon rank-sum test

因此这里很容易出现名称混淆。

---

# 7. Mann–Whitney U 的核心思想

假设：

```text
A = [1, 3, 5]
B = [2, 4, 6]
```

把所有数据放在一起：

```text
1  2  3  4  5  6
```

排序：

```text
值    rank    组
1      1     A
2      2     B
3      3     A
4      4     B
5      5     A
6      6     B
```

A 的 rank：

\[
1+3+5=9
\]

B 的 rank：

\[
2+4+6=12
\]

如果：

```text
A 和 B 来自相同分布
```

它们的 rank 通常应该相互混杂。

但如果变成：

```text
A = [1,2,3]
B = [10,11,12]
```

排序就是：

```text
A A A B B B
```

显然 B 基本总是比 A 大。

Mann–Whitney U 就是通过这种**相对排序关系**判断两个独立组是否存在差异。

---

# 8. U 到底是什么意思？

假设：

\[
n_A=3,\qquad n_B=3
\]

总共有：

\[
3\times3=9
\]

对跨组比较：

```text
A1 vs B1
A1 vs B2
A1 vs B3

A2 vs B1
...

A3 vs B3
```

因此 U 可以理解为：

> 一个组中的数据相对于另一个组中的数据“赢了多少次”。

例如：

```text
A = [1,2,3]
B = [10,11,12]
```

A 永远比 B 小。

反过来说 B 在所有：

\[
3\times3=9
\]

次比较中都更大。

所以它本质上是在研究：

\[
P(X_A > X_B)
\]

这样的概率关系。

---

# 9. Python 中的 Mann–Whitney U

SciPy：

```python
from scipy.stats import mannwhitneyu

A = [71, 74, 69, 76, 72]
B = [80, 79, 83, 75, 81]

result = mannwhitneyu(
    A,
    B,
    alternative="two-sided"
)

print("U statistic:", result.statistic)
print("p-value:", result.pvalue)
```

其中：

```python
alternative="two-sided"
```

表示：

\[
H_1:A\neq B
\]

还可以写：

```python
alternative="less"
```

表示大致检验：

\[
A < B
\]

或者：

```python
alternative="greater"
```

表示：

\[
A > B
\]

---

# 10. Mann–Whitney U 和 independent t-test

它们大致是这样的对应关系：

```text
两组独立样本
       │
       ▼
数据是否适合独立样本 t 检验？
       │
 ┌─────┴─────┐
 │           │
是           否
 │           │
 ▼           ▼
independent   Mann–
t-test        Whitney U
```

### independent t-test

重点关注：

\[
\mu_A-\mu_B
\]

即**均值差异**。

### Mann–Whitney U

重点关注：

\[
\text{两组数据的相对排序}
\]

因此严格来说不要简单地说：

> Mann–Whitney U 是“比较两个中位数”。

这个说法只有在两个总体的分布形状相似、主要是位置发生平移时，才比较合理。

更严谨地说：

> Mann–Whitney U 检验两个独立样本的分布位置/随机排序是否存在系统性差异。

---

# 11. Wilcoxon 和 Mann–Whitney U 最关键区别

你可以记住这张表：

| | Wilcoxon signed-rank | Mann–Whitney U |
|---|---|---|
| 中文 | Wilcoxon 符号秩检验 | Mann–Whitney U 检验 |
| 数据关系 | **配对** | **独立** |
| t 检验对应物 | paired t-test | independent t-test |
| 是否参数检验 | 否 | 否 |
| 核心 | 差值排名 | 两组混合后的排名 |
| 检验统计量 | \(W\) | \(U\) |
| 常用于 | 前后比较、同一被试两个模型 | 两组不同被试 |
| 对异常值 | 比 t 检验不敏感 | 比 t 检验不敏感 |

有一个特别方便的记忆方法：

\[
\boxed{
\text{Wilcoxon：先算 difference}
}
\]

\[
\boxed{
\text{Mann–Whitney：直接比较两个独立 group}
}
\]

# 12. 和你之前学的 t 检验放在一起

整个体系其实非常清楚：

```text
                    比较数据
                       │
            ┌──────────┴──────────┐
            │                     │
         单组/配对               两组独立
            │                     │
      ┌─────┴─────┐         ┌─────┴─────┐
      │           │         │           │
   参数检验    非参数检验   参数检验    非参数检验
      │           │         │           │
      ▼           ▼         ▼           ▼
 one-sample/   Wilcoxon   independent  Mann–
 paired t                t-test       Whitney U
```

比如你的 EEG/模型实验里：

**同样 20 个被试，比较 Model A 和 Model B：**

```text
paired t-test
或
Wilcoxon signed-rank
```

**20 个健康组和另外 20 个实验组：**

```text
independent t-test
或
Mann–Whitney U
```

## 13. 一个非常容易犯的错误

不要写成：

```python
wilcoxon(group_A, group_B)
```

只因为：

```text
len(group_A) == len(group_B)
```

就认为可以做 Wilcoxon。

**长度一样 ≠ 配对数据。**

配对意味着：

```text
A[0] ↔ B[0]
A[1] ↔ B[1]
A[2] ↔ B[2]
```

必须有实际实验意义上的一一对应关系。

如果只是恰好：

```text
20 人 vs 20 人
```

但不是同一个人，那么应该使用：

```python
mannwhitneyu()
```

而不是：

```python
wilcoxon()
```

---

最后可以把这四个检验记成一个很实用的口诀：

\[
\boxed{
\begin{aligned}
\text{单样本、正态} &\rightarrow \text{one-sample t}\\
\text{配对、正态} &\rightarrow \text{paired t}\\
\text{配对、非参数} &\rightarrow \text{Wilcoxon}\\
\text{独立、非参数} &\rightarrow \text{Mann–Whitney U}
\end{aligned}}
\]

而**两个独立样本、满足参数条件**时，就是：

\[
\boxed{\text{independent t-test}}
\]

如果你接下来想真正理解这两个检验，我建议下一步重点推演一次 **Wilcoxon 的 W 值到底怎么算出来**，以及 **Mann–Whitney 的 U 为什么等价于“成对胜负次数”**。这两个推演完，基本就不会再混淆它们了。
