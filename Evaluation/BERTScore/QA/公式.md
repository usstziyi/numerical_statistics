这里的 \(\lvert y\rvert\) **不是“\(y\) 的绝对值”**。

在 BERTScore 公式里：

\[
P=\frac{1}{|y|}\sum_{y_j}\max_i\cos(e(y_j),e(x_i))
\]

\(y\) 表示的是**生成句子的 token 序列**，所以：

\[
\boxed{|y|=\text{序列 }y\text{ 中 token 的数量}}
\]

也就是句子的长度。

例如：

\[
y=(\text{猫},\text{蹲},\text{在},\text{地毯},\text{上})
\]

一共有 5 个 token，因此：

\[
|y|=5
\]

于是：

\[
P=
\frac{1}{5}
\sum_{j=1}^{5}
\max_i\cos(e(y_j),e(x_i))
\]

这里除以 5，就是为了把 5 个 token 的最佳相似度**求平均**。

假设每个 token 的最佳匹配分数分别是：

\[
1.0,\ 0.85,\ 1.0,\ 0.8,\ 1.0
\]

那么：

\[
P=
\frac{1}{|y|}
(1+0.85+1+0.8+1)
\]

因为：

\[
|y|=5
\]

所以：

\[
P=\frac{4.65}{5}=0.93
\]

你之所以会觉得像绝对值，是因为数学里符号 \(|\cdot|\) 有多种含义：

- 如果里面是一个**数**：\(|x|\) 通常表示绝对值
- 如果里面是一个**集合**：\(|A|\) 表示集合元素个数
- 如果里面是一个**序列/字符串**：\(|y|\) 通常表示序列长度

所以在这里：

\[
\boxed{|y|\neq \text{绝对值}}
\]

而是：

\[
\boxed{|y|=\text{生成文本的 token 数量}}
\]

因此整个 Precision 公式其实可以更直观地写成：

\[
\boxed{
P=
\frac{
\text{所有生成 token 的最佳语义匹配分数之和}
}{
\text{生成 token 数量}
}
}
\]

也就是**平均最佳匹配相似度**。
